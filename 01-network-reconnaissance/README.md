# 🔎 Reconnaissance réseau

## 🎯 Objectif

Découvrir et analyser les équipements et services présents sur un réseau de laboratoire.

## 🧪 Environnement

- Kali Linux
- Ubuntu
- Metasploitable
- VirtualBox

## 🔧 Outils

- Nmap
- `ip`
- `ss`
- `arp`

## 📋 Travaux pratiques

Cette section sera complétée progressivement avec les résultats des manipulations réalisées dans le laboratoire.

## 📚 Compétences développées

- Identification des hôtes
- Analyse des adresses IP
- Identification des ports et services
- Compréhension de la surface d'exposition réseau
- Documentation des résultats

> ⚠️ Les manipulations sont réalisées uniquement dans un environnement de laboratoire autorisé.
